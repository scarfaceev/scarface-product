# ScarfaceEV website

The existing React + Vite website is organized in [`scarface-frontend/`](./scarface-frontend/). No backend is included in this repository.

See [`scarface-frontend/README.md`](./scarface-frontend/README.md) for installation, development, production build, asset, and configuration instructions.

The original charger image archive (`SCARFACEEV Tall Charger Front (1).zip`) is retained at the repository root as an untouched source backup. The extracted images used by the app are in `scarface-frontend/src/assets/images/charger-photos/`.
